= КАК ЗАПУСТИТЬ БОТА (панель управления каналом + автопостинг + модератор) =

ШАГ 1. Впиши свой user_id в config.py:
- Напиши в Телеграме боту @userinfobot
- Он ответит числом — это твой user_id
- Открой config.py и вместо 0 в строке ADMIN_ID = 0 вставь своё число
  Пример: ADMIN_ID = 123456789
- (Токен и канал уже вписаны)

ШАГ 2. Проверь, что бот добавлен в канал админом:
- Бот @KomnatStraha должен быть администратором канала
  с правом "Отправка сообщений" (для постов) — уже проверено

ШАГ 3. Заполни посты (опционально):
- Открой posts.txt, впиши записи, каждая с новой строки

ШАГ 4. Запуск:
- Двойной клик по "запустить_бота.bat"
- Или в папке: python bot.py

= ЧТО УМЕЕТ БОТ =

ДЛЯ ВСЕХ (в группе):
- модератор: бот сам удаляет сообщения с запрещёнными словами
  (config.py -> BANNED_WORDS)

ДЛЯ ТЕБЯ (в ЛС с ботом, по user_id):
- кнопки-меню панели:
  • Статистика (подписчики, статус автопостинга)
  • Пост в канал (впиши текст -> бот отправит)
  • Автопостинг (вкл/выкл)
- команды:
  • /post_now — отправить случайный пост из posts.txt сразу
  • /cancel — отмена действия

УДАЛЕНИЕ СООБЩЕНИЙ:
- Убрано намеренно (удаляешь сам вручную в Telegram).
- Бот только постит и модерирует (авто-удаление запрещённых слов).

ДЛЯ ОСТАЛЬНЫХ:
- в ЛС бот отвечает "Нет доступа" — панель только у тебя
